================================================================
 ISO comparison: NetBSD CLI (stock)  vs.  NetBSD CLI + ArduPilot
 repo: github.com/ukrcherry/ardupilot_nbsd
================================================================

What we built
-------------
1) netbsd-cli-iso/
   Plain vanilla NetBSD 11.0 amd64 install ISO. CLI-only (sysinst
   is curses; NetBSD has no GUI installer variant). Two build modes:
     MODE=build     - fetch src sets, run build.sh tools + release +
                      iso-image. ~1-2 hours, everything from source.
     MODE=download  - fetch the prebuilt stock ISO from cdn.NetBSD.org
                      and verify SHA512. ~1 minute.
   Output: standard installer, network install, or install from sets
   already on the CD (base+etc+kern+comp minimum).

2) netbsd-ardupilot-iso/
   Same base ISO + a /ardupilot/ directory containing:
     * pkgsrc pkgs re-tarred by pkg_tarup: bash, gmake, gawk, git-base,
       ccache, wget, python312, py-numpy, py-lxml, arm-none-eabi
       cross-toolchain gcc 13.2.0 (our custom local pkg from step 03)
     * The ArduPilot repo with build/ already compiled for MatekH743
     * postinstall.sh - pkg_adds everything after sysinst, drops the
       tree in /home/ardupilot, adds first user to `dialer` group
   Built by: run stage1 on a NetBSD host that already went through
   install-all.sh, then stage2 (xorriso) to splice payload into the
   base ISO from (1).

How they relate
================================================================

The ArduPilot ISO is built ON TOP OF the plain CLI NetBSD ISO:

    src.tgz              build.sh tools
   (from cdn.NetBSD.org)     |
           \\                 v
            +----------> build-netbsd-cli-iso.sh
                              |
                              v
                     NetBSD-11.0-amd64.iso  (~500 MB)
                              |
                              +--- deliverable A (plain CLI)
                              |
                              v
                     stage2-remaster-iso.sh <---- payload.tar.xz
                              |                        ^
                              v                        |
                     netbsd-ardupilot.iso              |
                          (~750 MB)                    |
                              |                stage1-build-payload.sh
                              |                        ^
                              +-- deliverable B         |
                                                       |
                                        (on a NetBSD host that ran
                                         install-all.sh from the
                                         parent ardupilot_nbsd repo)

If you already have a working stock ISO (either downloaded or built),
skip build-netbsd-cli-iso.sh entirely - pass it straight to stage2.


When each makes sense
================================================================

Plain CLI NetBSD ISO:
  * You want a general-purpose NetBSD install disk for something else.
  * You want to audit or rebuild the base from src.tgz for a reproducible
    build (MODE=build).
  * You're setting up multiple ArduPilot targets and only want to ship
    the payload separately; each new install starts from this ISO.
  * You want the smallest possible bootstrap surface area.

NetBSD + ArduPilot ISO:
  * Single-shot deployment of an ArduPilot dev/ground station box.
  * Offline install site: no network access after boot, everything
    needed is on the CD.
  * You want to preserve the exact toolchain versions you validated
    against (gcc 13.2.0 for arm-none-eabi, empy 3.3.4, etc.).
  * Airgapped or regulated environments where every package must be
    provided as a fixed artifact rather than fetched at install time.


Effort summary
================================================================

netbsd-cli-iso/                     netbsd-ardupilot-iso/
  build-netbsd-cli-iso.sh   ~85 L     build-netbsd-iso.sh       39 L
                                      stage1-build-payload.sh   66 L
                                      stage2-remaster-iso.sh    38 L
                                      postinstall.sh            55 L
                                      ---
  ~85 L wraps build.sh                ~198 L on top of stock ISO

Both together: ~285 lines of shell that produce two related ISOs. The
plain-CLI script leans on build.sh (many thousands of lines of upstream
Makefiles and BUILDING.mk); the ArduPilot side additionally leans on
pkg_tarup (~500 lines) and xorriso.

    ./netbsd-cli-iso/build-netbsd-cli-iso.sh

    # B) ArduPilot variant (needs a NetBSD host with install-all.sh

    ./netbsd-ardupilot-iso/build-netbsd-iso.sh stage1

        netbsd-11.0-amd64-cli.iso  netbsd-ardupilot.iso
